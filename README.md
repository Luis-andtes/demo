# SCOPE

Demo del Semillero de Investigación de Economía y Finanzas para las Organizaciones.

La versión estática lista para publicar se encuentra en `dist/`.

## Despliegue en Vercel

Importa este repositorio en Vercel con el preset **Other** y deja vacío el comando de compilación. La configuración incluida publica automáticamente el contenido de `dist/`.
